# UI/UX Ruang Aman

## Halaman MVP

- Landing page
- Register, login, dan forgot password
- Form kasus dan upload bukti
- Status pemrosesan
- Hasil ringkasan dan riwayat kasus
- SafeMap dan daftar kontak bantuan

## Prinsip desain

- Bahasa Indonesia yang tenang, jelas, dan tidak menyalahkan korban.
- Jangan tampilkan thumbnail atau isi bukti secara tiba-tiba.
- Sediakan konfirmasi sebelum hapus dan tombol keluar cepat jika disepakati tim.
- Form dapat disimpan sebagai draft.
- Setiap proses memiliki loading, error, empty, dan success state.
- Desain responsif mulai dari lebar mobile, tetapi tetap nyaman di desktop.
