# Privacy-First-Evidence-SafeMap

Platform pengolahan data bukti kekerasan berbasis gender dan safemap. platform ini digunakan sebagai lapisan awal terhadap korban kekerasan berbasis gender

# Teknis Platform Secara Keseluruhan
User upload file melalui web
            |
Backend mengambil data nya dan menyimpan di Database
            |
Machine Learning mengambil data dari DB dan mengolah data menjadi 1 file akhir
